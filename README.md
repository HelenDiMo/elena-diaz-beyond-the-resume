# Elena Díaz · Beyond the Resume

Portfolio profesional desarrollado para presentar mi experiencia, proyectos y evolución hacia el ámbito de Data e Inteligencia Artificial.

## ✦ Sobre el proyecto

Este portfolio nace con la intención de mostrar algo que un CV tradicional no puede contar por completo: cómo trabajo, cómo pienso y qué soy capaz de construir.

El proyecto combina mi experiencia previa en administración, finanzas y operaciones con mi formación actual en análisis de datos, Python e Inteligencia Artificial.

## 🚀 Desarrollo local

Clonar el repositorio:

```bash
git clone https://github.com/HelenDiMo/elena-diaz-beyond-the-resume.git
cd elena-diaz-beyond-the-resume
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

El proyecto estará disponible en:

```
http://localhost:3000
```

Para generar una build de producción:

```bash
npm run build
```
